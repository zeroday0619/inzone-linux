# 기능 추적

공간 음향·개인화·자동 음량·프로파일·장치 제어는 아래와 같이 구현했습니다. 검사는 Linux에서 수행합니다.

| 기능 | 상태 | 검사 / 사용 조건 |
|---|---|---|
| 7.1 공간 음향·H9 II 보정·내부 ALC | 구현 | PipeWire 채널 응답·음량 제한·무음 복귀 |
| 출력 ALC·DRC 낮음/높음/끔·마이크 AGC | 구현 | LADSPA 처리·블록 크기·초기화·실제 장치 로딩 |
| Sony 10밴드 EQ·기본/몰입 음장·7개 프리셋 | 구현 | 원본 계수 표 사용, Linux 인라인 처리 검사 |
| HKI/BA 개인화 가져오기·전환 | 구현 | cipher 5/7·정규화·손상 거부·교체 검사 |
| 귀 사진 분석 | 제공하지 않음 | 이미 생성된 HKI/BA 파일을 로컬에서 가져옴 |
| FPS/음악/통화/기본/서라운드/복원 | 구현 | 실제 전환·대상 연결·싱크 생성/해제 검사 |
| 프로파일별 EQ·DRC·ALC·AGC·HRTF 저장 | 구현 | TUI·CLI, 실패 시 이전 설정 복원 |
| Linux JSON·SoundProfile.json 가져오기/내보내기 | 구현 | Linux에서 형식·왕복 검사 |
| 자동 프로파일 전환 | 구현 | Linux/Wine 실행 파일·우선순위·수동 선택 우선. 기본 꺼짐 |
| Game/Chat 음량·마이크 음량/음소거·마이크 듣기 | 구현 | 장치 TUI. 마이크 듣기는 최대 30초 |
| 배터리·마이크·Bluetooth·펌웨어 버전 조회 | 구현 | 실제 H9 II HID 응답 확인 |
| ANC·주변 소리·음성 집중·사이드톤·Game/Chat 균형 | 구현 | 상태 조회·사이드톤 변경/조회/복원 검사 |
| NC 버튼·시작 시 NC/Bluetooth·자동 전원 끄기 | 구현 | 상태 조회·입력 범위 검사 |
| 음성 안내 언어·안내음 | 구현 | 상태 조회·입력 값 정의 |
| 고해상도 무손실 파일 재생 | 구현 | 고품질 48 kHz 변환. USB 출력은 16 bit/48 kHz |
| 펌웨어 최신 버전 확인·업데이트 | 미구현 | 현재 버전 조회만 제공 |

개인화 적용: TUI I(로컬 파일 가져오기) 후 서라운드에서 P로 선택합니다. 현재 본인 개인화 파일이 없으면 기본 HRTF를 사용합니다.
